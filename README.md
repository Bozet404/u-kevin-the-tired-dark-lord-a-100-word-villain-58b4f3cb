# The Tired Dark Lord: A 100-Word Villain Monologue

Entry for the [make.fun bounty "The Tired Dark Lord: A 100-Word Villain Monologue"](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) ($2, 10 places paid).

## What it is

`main.ts` writes a single 100-word monologue to `/output/entry.txt`. The speaker
is a fantasy villain thirty years into his reign: the eclipse rite is still
ready, the chalk ring is still drawn, but the third step has been loose since
the siege of Aldermere, the choir is down to two basses and a boy who loses
the words, the flags have gone grey and the ravens have stopped answering.
He never says he is tired — the weariness lives in the pauses, the small
chores nobody fixed, and the last line, where for once he would like to end
something before dawn.

## Run it

```sh
node main.ts   # writes /output/entry.txt (Node 22+)
```

The output is exactly 100 words and 530 characters, inside the gate's 1–600
character window, deterministic across runs.
